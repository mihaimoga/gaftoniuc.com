# gaftoniuc.com

[gaftoniuc.com](https://www.gaftoniuc.com) is the official website for Ștefan Cristian Gaftoniuc, a certified translator and interpreter authorized by the Romanian Ministry of Justice. The site provides professional translation and interpretation services for English and French, focusing on legal, official, and business documents.

## ✨ Features

- Responsive design for all devices
- Clear presentation of services and credentials
- Contact form for inquiries
- SEO-friendly structure

## 🚀 Installation
Clone the repository:
```
git clone https://github.com/mihaimoga/gaftoniuc.com
```
Navigate to the project folder and open index.php in your browser.
